# House Price Prediction

## Project Overview

This project uses Machine Learning to predict house prices based on different property features such as size, location, and number of rooms.

The goal is to build a model that can estimate house prices as accurately as possible using real-world data.

---

## Dataset

The dataset contains various features related to houses such as:

- Number of bedrooms
- Number of bathrooms
- Living area size
- Lot size
- Year built
- Other property features

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Prediction

---

## Results

- **Model Performance (R² Score): 80%**

The model explains around 80% of the variation in house prices.
